some other data points we can consider: 
1. The Data: DPA (s) status: 
If an area is a "DPA," Nuvo Health can hire from a much larger pool of doctors. If it's not a DPA, they can only hire local doctors, which is much more expensive and competitive.
2. Number of Pharmacies or Pathology centers in the same suburb: 
Nuvo is multidisciplinary so having a pharmacy nearby is convenient for patients and staff


What we’ll use: Multi-Criteria Decision Analysis (MCDA)
- v1 scaled every criterion min-max within the cohort: higher-better = (x-min)/(max-min); lower-better = (max-x)/(max-min). SUPERSEDED - v2 gives each criterion its own value function (rank percentile, log ramp, inverted U) because two of the four criteria are not monotone. See the criteria table in README.md.
